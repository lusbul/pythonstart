ЯК ОНОВИТИ GITHUB PAGES
1. Розпакуйте ZIP на комп’ютері.
2. Відкрийте репозиторій pythonstart на GitHub.
3. Add file → Upload files: перетягніть вміст папки pythonstart,
   зберігаючи папку assets. Файл index.html має бути в корені репозиторію.
4. Збережіть коміт. Дочекайтеся завершення публікації GitHub Pages.
5. Відкрийте сайт та оновіть Ctrl+F5.

ЩО ДОДАНО
21 тема у 6 розділах. У кожній темі 3 перевірювані завдання:
прогноз, вибір рішення та конструктор програми. Разом 63 завдання.
Заповнені Turtle, Pygame Zero, Tkinter; у вступі до бібліотек — math і random.
Усі попередні інтерактиви, зображення, базові стилі й адреси залишено.
Нові спільні файли: practice.html, practice-data.js, practice.js,
practice.css, progress.js, report.html, report.js,
legacy-report.js, report-print.css.

ЗВІТ
На головній та сторінках розділів є «Мій звіт · PDF».
Можна обрати тему, розділ або весь курс. Звіт формується поступово:
невиконані завдання не зараховуються. Для нових практик відображаються
відповіді, усі перевірені спроби, завершення та рефлексія.
У старих квестах — останній зафіксований стан і власні роботи;
історія їхніх спроб не підраховується заднім числом.
Кнопка PDF відкриває друк браузера: оберіть «Зберегти як PDF».
Українські літери друкуються засобами браузера без додаткових бібліотек.
Результати залишаються у браузері на цьому пристрої. Очищення даних
браузера видаляє прогрес. JSON — резервна копія для зберігання;
імпортування цієї копії через інтерфейс наразі немає.
Перед очищенням прогресу збережіть PDF. Автоматичного надсилання вчителю немає.

ЗАПУСК ПРОГРАМ
Нові практики перевіряють прогноз, рішення та порядок готових рядків.
Це конструктори, не універсальне середовище виконання Python.
Завантажений .py можна виконати на комп’ютері.
Turtle і Tkinter потребують локального Python із графічною підтримкою.
Для Pygame Zero: встановіть pgzero, запустіть pgzrun libraries-3.py.
Наявна гра «День рішень» запускає Python через Pyodide і потребує
інтернет-доступу до cdn.jsdelivr.net. Інші нові практики не потребують CDN.
Працюйте через GitHub Pages; для збереження прогресу уникайте file://.

ПЕРЕВІРКА
Перевірено локальні посилання, синтаксис усіх JavaScript,
синтаксис зібраних Python-програм і результати 19 виконуваних прикладів.
Окремо перевірено облік спроб, збереження й захист тексту звіту.
Візуальна перевірка браузера та фактичний друк PDF у цьому середовищі
не виконувалися. Після завантаження перевірте PDF у своєму браузері.
