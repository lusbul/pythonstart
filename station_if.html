УСІ СИСТЕМИ ПРАЦЮЮТЬ

Станцію IF відновлено! 🚀

Ви перевірили межі, порівняли числа й текст та налаштували три гілки рішення.

Шпаргалка: введення, виведення та умови

input() отримує текст; int(input()) перетворює його на ціле число; print() виводить результат.

== — дорівнює; != — не дорівнює; > — більше; >= — більше або дорівнює; < — менше; <= — менше або дорівнює.

if умова:
    print("Умова істинна")
else:
    print("Умова хибна")

elif перевіряється, якщо попередня умова хибна. Відступ у кожній гілці — чотири пробіли. Для порівняння потрібне ==, а = використовується для присвоєння.

Прогрес зберігається в цьому браузері, якщо він дозволяє локальне збереження. Дані нікуди не надсилаються.
