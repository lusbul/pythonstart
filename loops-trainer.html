Покроковий симулятор
Змініть тип циклу, старт, крок та межу. Програма виконується безпечно: максимум 30 кроків. Спостерігайте за значеннями.


Текстова гра «Таємнича бібліотека»
Дослідіть, як while True створює ігрове меню, а break завершує гру. Після проходження складіть власну ідею гри для ШІ.
while True:
    print("1 - Шукати ключ")
    print("2 - Відкрити двері")
    print("3 - Вийти")
    choice = input("Дія: ")
    if choice == "3":
        break
    if choice == "1":
        print("Шукаємо ключ")
        continue
    if choice == "2":
        print("Перевіряємо двері")


Підсумковий звіт
Звіт містить виконані місії, прогнози, параметри симулятора та ідею текстової гри. Він не замінює підсумковий PDF усього курсу.
