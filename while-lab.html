2. Мініпроєкт «Текстова пригода: ключ від вежі»
Ситуація. На дні відкритих дверей гурток хоче запропонувати гостям коротку текстову гру. Гравець має сам обирати дії, отримувати зрозумілі відповіді й мати можливість завершити гру.
Завдання для розробника. Підготуйте й протестуйте прототип пригоди «Ключ від вежі» як розробник ігрового застосунку. Скористайтеся готовою моделлю, а потім адаптуйте її ідею у ШІ-майстерні нижче.
Що має робити програма:
  • Меню повторюється після кожної дії, доки гравець не переміг або не обрав вихід.
  • Без ключа вежа не відчиняється; після знаходження ключа її можна відчинити. У Python повторення забезпечує while True, завершення - break.
Як перевірити результат. Спробуйте відчинити вежу без ключа; потім знайдіть ключ і повторіть спробу. Почніть заново й оберіть вихід. В обох випадках завершення гра повинна припинити приймати ігрові дії.
inventory = []
while True:
    command = input("Ваш вибір: ")
    if command == "ліс":
        print("Ви в лісі")
    elif command == "ключ":
        inventory.append("ключ")
    elif command == "вежа" and "ключ" in inventory:
        print("Перемога!")
        break
    elif command == "вихід":
        break
Спробуйте спочатку відчинити вежу без ключа. Після перемоги поясніть, навіщо потрібен break.
3. ШІ-майстерня «Створіть власну текстову гру»
Замовник - гурток, якому потрібна нова коротка гра для гостей. Оберіть світ і механіку, сформуйте промпт для розробки. У готовому Python-коді перевірте меню, реакцію на неправильну команду та можливість виходу. Після перевірки запропонуйте одне вдосконалення для гравця.
Перевірка покаже, чи є в коді цикл, введення команд, варіанти дій та завершення гри.
Це структурна перевірка, а не виконання Python. Запустіть код у Вашому Python-середовищі й перевірте всі варіанти команд.
